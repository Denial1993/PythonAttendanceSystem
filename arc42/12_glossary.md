# 12. 詞彙表

| 詞彙 | 說明 |
| --- | --- |
| 工號 (Username) | 系統中的唯一辨識碼，亦作為登入帳號。 |
| RAG | Retrieval-Augmented Generation，檢索增強生成，本系統用於將資料庫紀錄餵給 AI 參考。 |
| 特休 (Annual Leave) | 根據到職日計算的法定給薪休假。 |
| 補班日 | 將休息日調整為工作日的特殊日期。 |
| Role 1 | 系統管理員 (Admin)，具備最高權限。 |
| Role 2 | 經理 (Manager)，可審核假單與查看員工名冊。 |
| Role 3 | 一般員工 (Normal User)，僅能操作個人打卡與請假。 |
| SPA | Single Page Application，單頁應用程式（即本系統前端 Vue 之運作模式）。 |
