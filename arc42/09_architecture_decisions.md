# 09. 架構決策

### ADR-001：選擇 FastAPI 作為後端框架
- **狀態**：已採用
- **背景**：系統需要快速開發、具備良好的 Pydantic 整合以及自動化 API 文件。
- **決策**：使用 Python FastAPI 框架。
- **後果**：API 效能優秀，但團隊需熟悉 Python 非同步 (async/await) 概念。

### ADR-002：前端 Vue 3 與單一部署模式
- **狀態**：已採用
- **背景**：為了簡化部署流程，避免在 Render 分別管理前端與後端主機。
- **決策**：將 Vue 建置後的 `dist` 併入 FastAPI 靜態目錄，透過單一 Docker 容器部署。
- **後果**：部署簡單，但在開發期需要開啟兩個 Server (Vite dev + FastAPI) 並處理 CORS 問題。

### ADR-003：串接 Gemini 進行差勤諮詢
- **狀態**：已採用
- **背景**：使用者查詢歷史紀錄較為繁瑣，希望能以對話方式快速取得答案。
- **決策**：導入 Gemini Flash 模型，並採用 RAG 模式提供即時差勤資料。
- **後果**：顯著提升用戶體驗，但需依賴外部 API 穩定性。
