# 04. 解決方案策略

## 4.1 技術選型決策
- **FastAPI**：利用其非同步處理能力與自動生成 OpenAPI 文件的特性，加速 API 開發。
- **Vue 3 (Composition API)**：提供靈活的元件化開發，提升前端維護性。
- **PostgreSQL**：選用關聯式資料庫以確保差勤紀錄與請假時數的資料完整性。

## 4.2 前後端整合
- **單一存儲庫 (Monorepo)**：前端與後端程式碼位於同一個 Git 儲存庫。
- **打包策略**：前端透過 Vite 編譯後，將 `dist` 資料夾複製到後端 `static` 目錄下，實現全端單一 Docker Image 部署。

## 4.3 智慧化方案
- **RAG 架構**：後端 `chat.py` 路由先從資料庫撈取特定員工的近期出勤紀錄，將其作為 Context 餵給 Gemini 模型，實現精準的個人化回覆。
